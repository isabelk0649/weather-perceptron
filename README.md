# Weather Classification using a Simple Perceptron

A Python-based implementation of a Perceptron learning algorithm to predict precipitation based on normalized temperature and humidity data. This project demonstrates fundamental concepts in binary classification, linear decision boundaries, and data visualization.

## 🚀 Overview
The goal of this project is to classify weather instances as "Rain" or "No Rain." It utilizes a Perceptron model to iteratively adjust weights and find a linear hyperplane that separates the two classes.

### Key Features:
* **Data Visualization:** Plots raw weather data to analyze linear separability.
* **Perceptron Implementation:** Custom implementation of the weight update rule.
* **Decision Boundary Mapping:** Visualizes how the model "sees" the boundary between classes using contour plots.
* **Train-Test Splitting:** Evaluates model performance across different data distributions.

## 🛠️ Tech Stack
* **Language:** Python 3.10+
* **Libraries:** NumPy (Matrix Math), Pandas (Data Handling), Matplotlib (Visualization)
